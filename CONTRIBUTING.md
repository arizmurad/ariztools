# Contributing to ariztools

This repository is a catalog. Send arizdot code changes and bug reports to the [arizdot repository](https://github.com/arizmurad/arizdot).

For a catalog change, fork this repository, make a focused edit, and open a pull request explaining the corrected description or link. The maintainer **@arizmurad** reviews and accepts changes before they are merged. CODEOWNERS identifies the reviewer; required review must also be enabled in GitHub repository settings.

You may fork, modify and redistribute this catalog under the MIT license with its notice retained. Publishing your own fork does not require approval; merging into the official repository does.
