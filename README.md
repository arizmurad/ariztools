### arizdot

A small dot for Codex and Claude. Hover to see work in progress; click a task to see what finished, what is running and what comes next.

Run both assistants at once: Codex and Claude tasks appear together in a single panel with separate progress and clickable subprocess details.

![arizdot with concurrent tasks and inline milestones](https://raw.githubusercontent.com/arizmurad/arizdot/main/docs/assets/overview.png)

The Codex, Claude and combined Windows packages are maintained in the [arizdot repository](https://github.com/arizmurad/arizdot). The preview uses illustrative screenshots, runs locally, and keeps progress tied to recorded evidence.
